# Independent-cohort validation: inputs and scope

`src/run_wang_external_validation.py` evaluates four fixed information blocks on
the 86-cell cohort released with Wang, Gao and Tian (Zenodo,
[10.5281/zenodo.14859405](https://doi.org/10.5281/zenodo.14859405)):

1. capacity only;
2. five explicit snapshot measurements (capacity, voltage, internal resistance,
   coulombic efficiency, energy efficiency);
3. the 108 implicit single-cycle features;
4. the explicit and implicit features combined.

Each model is an L2 logistic regression with `C = 1`, median imputation and
standardization fitted inside each protocol-held-out training fold. The 95 %
interval resamples the 16 protocol groups 1,000 times.

## What is included

- `results_reference/wang_external_validation_metrics.csv` — the published
  metrics (balanced accuracy 0.660 / 0.743 / 0.627 / 0.639, AUC, Brier,
  confusion counts, bootstrap interval).
- `results_reference/wang_external_validation_predictions.csv` — held-out
  predictions for all 86 cells.
- `results_reference/wang_external_validation_report.json` — run report.

These files are what Figure 5 and Table S3 use, so the figure and the
supplementary table are regenerated by `src/make_figures.py` and
`src/make_supplementary.py` without rerunning the external model.

## What is not included

The script expects two prepared matrices that are not redistributed here:

- `data/wang/wang_features.csv` — five explicit measurements plus the 108
  implicit single-cycle features per cell;
- `data/wang/wang_capacity_trajectories.csv` — spline-interpolated capacity
  series from every fifth cycle.

They are a re-derivation of third-party raw cycling files and follow the source
authors' extraction conventions. To rerun the external validation, obtain the
public record, build the two matrices with the column names expected by the
script, and place them in `data/wang/`. The published outputs above remain the
reference for the numbers reported in the article.

The identity map between processed `bat_num` values and the experiment's
battery identifiers is reproducible from the released archive and is documented
in the source record's Supplementary Table S2; it is not redistributed here.
